# Gabber website

Static public website for the Gabber mobile application.

## Local preview

Serve the `dist` directory with any static HTTP server. All pages are plain HTML,
CSS, and JavaScript and require no build step.

## Before public launch

- Replace the beta download placeholder with the signed APK or Play Store URL.
- Add an official support email address to the support, privacy, and deletion pages.
- Have the privacy policy and terms reviewed for the final company entity and data practices.
